# مشروع STEM — مساعد ذكي لمشروع STEM

## المتطلبات
- Python 3.10 أو أحدث.
- اتصال بالإنترنت.
- مفتاح OpenAI API. قد يتطلب استخدام API تفعيل الفوترة أو وجود رصيد في حساب API، وهو منفصل عن اشتراك ChatGPT.

## التشغيل على Windows
1. ثبّت Python من https://www.python.org/downloads/، وفعّل خيار `Add Python to PATH` أثناء التثبيت.
2. فك ضغط المشروع وافتح مجلده.
3. افتح Command Prompt أو PowerShell داخل المجلد.
4. أنشئ بيئة افتراضية:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   إذا كنت تستخدم Command Prompt بدل PowerShell، شغّل:
   ```cmd
   .venv\Scripts\activate.bat
   ```

5. ثبّت المكتبات:
   ```powershell
   python -m pip install -r requirements.txt
   ```

6. انسخ `.env.example` إلى ملف جديد اسمه `.env` في المجلد نفسه.
7. افتح `.env` بمحرر نصوص، واستبدل `ضع_مفتاح_API_هنا` بمفتاح API الخاص بك. لا تشارك المفتاح ولا ترفعه إلى GitHub.
8. شغّل التطبيق:
   ```powershell
   streamlit run app.py
   ```
9. افتح الرابط المحلي الذي يظهر في الطرفية، وغالبًا يكون `http://localhost:8501`.

## الميزات
- واجهة محادثة عبر المتصفح.
- حفظ سياق آخر 20 رسالة أثناء جلسة التطبيق.
- اختيار شخصية المساعد وطول الإجابة.
- اقتراحات جاهزة ومسح المحادثة.
- معالجة أخطاء شائعة في API.

## ملاحظات
- غيّر `OPENAI_MODEL` في `.env` إلى اسم نموذج متاح لحسابك إذا لم يكن `gpt-5.5` متاحًا.
- مفتاح API يختلف عن اشتراك ChatGPT، وقد تُحتسب رسوم على الاستخدام.
- هذه نسخة أولية تعليمية؛ سجل المحادثة محفوظ في ذاكرة جلسة Streamlit فقط ولا يُحفظ كقاعدة بيانات دائمة.


## ميزة التحقق من التحديثات
- الإصدار الحالي معرف داخل `app.py` عبر `APP_VERSION`.
- انشر ملف JSON عام عبر HTTPS يحتوي على `version` و`release_url`، مثل:
  ```json
  {
    "version": "1.0.1",
    "release_url": "https://example.com/releases"
  }
  ```
- ضع رابط ملف JSON في خانة "رابط ملف التحديثات (JSON)" في الشريط الجانبي، أو عيّن متغير البيئة `STEM_UPDATE_MANIFEST_URL`.
- عند إصدار تحديث، ارفع نسخة الكود الجديدة إلى استضافة التطبيق، وحدّث رقم `APP_VERSION` وملف JSON.
- في تطبيق الويب، المستخدمون الذين يفتحون نفس الاستضافة يحصلون على الكود المنشور مركزيًا بعد إعادة التحميل/إعادة تشغيل التطبيق. زر التحقق ينبههم بوجود إصدار جديد، لكنه لا يستطيع تبديل كود الخادم من متصفحهم.
- لا تستخدم روابط HTTP غير المشفرة؛ يجب أن يكون رابط ملف التحديثات HTTPS.
